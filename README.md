# Формулировка

## Требования к сборке проекта

- Использовать task-менеджер и препроцессоры/постпроцессоры (webpack/vite & postcss/scss)
- Использовать пакет линтирования ESLint для JS/TS с правилами от Цифрового Элемента
- В сборке должны присутствовать как минимум три команды:
  - запуск в режиме разработки
  - запуск в режиме production
  - линтирование исходных файлов

---

## Требования к HTML/CSS

- Использовать БЭМ, валидную и семантически верную разметку
- Верстать при помощи **flex** или **grid**, адаптировать макет до **360px**
- Использовать формат **SVG** для иконок
- Проверить на кроссбраузерность (Chrome, Firefox, последние версии мобильных браузеров)
- Не использовать сетки и иные CSS-пакеты (кроме reset/normalize)
- Модальные окна должны закрываться:
  - по клику на крестик
  - по клику на фоновую тень  
  При появлении окна необходимо блокировать возможность скроллинга страницы
- Стиль модального окна и фонового оверлея задавать самостоятельно
- Будет плюсом применение различных эффектов и анимаций

---

## Требования к JavaScript / TypeScript

- Использовать **ES6+**
- Код должен быть на чистом JS или TS:
  - без сторонних библиотек/фреймворков
  - без `console.log`, `alert`, лишних комментариев
- Семантически грамотные имена методов и переменных
- События на элементах должны содержать лишь вызов метода обработчика события
- Будет плюсом:
  - использование **ES6-классов**
  - модульный подход при написании функционала

---

## Задание

1. Сверстать фрейм **"Homepage"** (фрейм “Contact us” верстать не нужно) с учётом вышеуказанных требований.
2. Сделать открытие модального окна при клике на кнопку **“Let’s Talk"** на главной странице.
   - В модальном окне должна находиться форма.
   - Форму взять с фрейма **"Contact Us"**.
3. Сделать **валидацию для формы** без использования стандартного браузерного функционала (атрибутов `required`).
4. После успешной валидации реализовать **отправку формы** (URL для отправки может быть любым).
5. После успешной отправки формы показать **попап с текстом**:
   - `"Your message successfully sent"` или аналогичным.

---

## На что обратить особое внимание

- Возможность переиспользовать код там, где это возможно
- Наличие минимальной архитектуры, разделение CSS-блоков и JS-модулей на отдельные файлы
- Качество верстки на мобильных устройствах и планшетах
- Работоспособность сборки в **dev-** и **prod-режимах**
- Отсутствие critical/high npm-зависимостей
